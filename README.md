# Эмулятор оболочки UNIX, вариант 8

Практическая работа 1. Консольная программа на Python, которая поэтапно
эмулирует команды UNIX-подобной оболочки. Этапы 1 и 2: интерактивный
REPL, обработка кавычек, заглушки `ls` и `cd`, команда `exit`, параметры
запуска, YAML-конфигурация и стартовый сценарий.

## Требования и запуск

Нужен Python 3.10 или новее. Дополнительные пакеты не требуются.
Из корня репозитория выполните `run.bat` в Windows или
`python -m src.shell` в любой ОС. Сборка не требуется.

## Команды и настройки

- `ls [аргументы]` и `cd [аргументы]` пока печатают имя и разобранные
  аргументы. Состояние файловой системы на этом этапе не меняется.
- `exit` завершает работу; аргументы для него недопустимы.
- Приглашение содержит реальные имя пользователя и имя компьютера.
- `--vfs PATH` (или `--vfs-path`) задает путь к будущему ZIP-образу VFS.
- `--startup PATH` (или `--startup-script`) задает стартовый сценарий.
- `--config PATH` задает YAML-конфигурацию. Она может содержать поля
  `vfs_path` и `startup_script`. Значения файла имеют приоритет над CLI;
  относительные пути файла отсчитываются от его каталога.
- На этапе 2 все итоговые параметры печатаются при старте. VFS пока не
  загружается.
- В сценарии каждая строка является командой. Пустые строки и комментарии
  `#` игнорируются. Ввод и вывод показываются как диалог. Ошибка команды
  сообщает путь и номер строки и завершает программу с кодом 1.

## Пример диалога

```text
user@host:~$ ls "two words" file
ls: ['two words', 'file']
user@host:~$ bad
shell: команда не найдена: bad
user@host:~$ exit
```

`python -m unittest discover -s tests -v`

В Windows можно запустить `examples\stage2_cli.bat`,
`examples\stage2_config.bat` и `examples\stage2_errors.bat`.

Каждый этап сохраняется отдельным коммитом. В следующих коммитах
заглушки сменятся рабочими командами.
