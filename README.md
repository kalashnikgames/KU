# Эмулятор оболочки UNIX, вариант 8

Практическая работа 1. Консольная программа на Python, которая поэтапно
эмулирует команды UNIX-подобной оболочки. Текущий коммит содержит этап 1:
интерактивный REPL, обработку кавычек, заглушки `ls` и `cd`, команду `exit`
и сообщения об ошибках.

## Требования и запуск

Нужен Python 3.10 или новее. Дополнительные пакеты не требуются.
Из корня репозитория выполните `run.bat` в Windows или
`python -m src.shell` в любой ОС. Сборка не требуется.

## Команды и настройки

- `ls [аргументы]` и `cd [аргументы]` пока печатают имя и разобранные
  аргументы. Состояние файловой системы на этом этапе не меняется.
- `exit` завершает работу; аргументы для него недопустимы.
- Приглашение содержит реальные имя пользователя и имя компьютера.
- Параметров запуска на этом этапе нет.

## Пример диалога

```text
user@host:~$ ls "two words" file
ls: ['two words', 'file']
user@host:~$ bad
shell: команда не найдена: bad
user@host:~$ exit
```

## Проверка

`python -m unittest discover -s tests -v`

Каждый этап сохраняется отдельным коммитом. В следующих коммитах
заглушки сменятся рабочими командами.
